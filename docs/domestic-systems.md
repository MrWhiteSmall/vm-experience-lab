# 国产操作系统候选

核实日期：2026-10-16。“国产”在这里说明发行版、项目与社区的来源，不等于整个软件栈由单一国家编写，也不表示使用独立于 Linux 的内核。

| 项目 | 类型与特色 | 适合的体验方式 | 官方入口 |
|---|---|---|---|
| deepin 深度 | 中国发起的 Linux 桌面发行版，DDE 桌面、控制中心和配套应用 | 桌面交互，优先选择能在本机虚拟设备上运行的版本 | https://www.deepin.org/zh/ |
| openKylin 开放麒麟 | 开放原子开源基金会孵化及运营的开源项目，桌面体验可关注 UKUI | 桌面交互；具体版本、架构、镜像体积和启动兼容性仍需调研 | https://www.openkylin.top/ |
| openEuler 开源欧拉 | 中国发起的开源 Linux 操作系统社区，覆盖服务器、云、边缘等场景 | 更适合终端、系统管理与服务实验，通常不以图形桌面作为第一体验目标 | https://www.openeuler.org/zh/ |
| OpenCloudOS | 中国厂商、社区与开发者共同参与的开源操作系统项目，偏云与服务器 | 终端与服务器任务；后续独立核实所选版本 | https://www.opencloudos.org/ |

国产商业桌面产品还包括统信 UOS、银河麒麟等，可另行调查试用入口、版本资源与授权条件。openKylin 不应与银河麒麟直接视为同一产品。DDE、UKUI 是桌面环境，不是和 Linux 并列的内核。

第一轮 20 项目录中，明确列入的国产发行版是 deepin。本轮新建项目时加入 openKylin 的介绍光盘；openEuler、OpenCloudOS 暂在收藏手记中介绍，尚未放入可启动清单。

deepin 已核实的 25.2.0 ARM64 ISO 为 5,509,810,176 字节，约 5.13 GiB；本轮没有下载。ARM64 只表示指令架构，通用虚拟机启动、图形设备与输入兼容性仍待验证。openKylin 尚未锁定版本，不填写猜测的镜像体积或最低配置。

官网页面快照保存在本目录的 `*-official.html`。其中 deepin 的 `/zh/about/` 地址实际返回了站点附件页，因此国产来源与 DDE 判断同时参考上一轮 deepin 官方下载与项目入口资料，不把该附件页当作完整项目介绍。
